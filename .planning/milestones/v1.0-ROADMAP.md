# Milestone v1.0: Fundação

**Status:** ✅ SHIPPED 2026-05-30
**Phases:** 01–05
**Total Plans:** 25

## Overview

Estabelece a fundação técnica completa do backend Caramello: stack async, autenticação
Keycloak, arquitetura por domínios, domínio families, servidor MCP, containerização e
infraestrutura de testes. Nenhum domínio de negócio adicional pode ser construído com
segurança sem este alicerce.

## Milestone Summary

**Decisões Chave:**

- Keycloak como único provedor de auth (reverteu Logto) — clients dev/prod já em infra
- asyncpg substituiu psycopg2-binary — sem suporte a SQLite
- Arquitetura por domínios (users/, families/, shared/) substituiu camadas planas
- DSL com campo `domain` gera código em `src/caramello/{domain}/`
- FamilyInvitation redesenhada: pré-registro por email (D-01) vs convite por código
- FAMILY-04/05/06 (fluxo de convite reutilizável) deferidos para M2 — fora do escopo do grupo familiar fechado
- Testes contra caramello_dev com rollback por savepoint — sem banco de teste separado
- fastapi-mcp 0.4.0 expõe endpoints FastAPI diretamente como ferramentas MCP
- DB naming: caramello (prod), caramello_dev (dev)

**Débito Técnico:**

- UAT E2E com Keycloak real + PostgreSQL nunca executado em ambiente real (3 itens em 03-07 + 4 itens em 05-HUMAN-UAT.md)
- docker build/run não verificado no sandbox (sem permissão ao Docker socket)
- SAWarning SQLAlchemy de overlaps corrigido na M1 tardiamente (pós Phase 5)

**Requisitos Deferidos para M2:**

- FAMILY-04: código de convite reutilizável
- FAMILY-05: solicitação de entrada via convite
- FAMILY-06: aprovação/rejeição de solicitações

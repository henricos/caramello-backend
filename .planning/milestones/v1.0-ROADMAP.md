# Milestone v1.0: Foundation

**Status:** ✅ SHIPPED 2026-05-30
**Phases:** 01–05
**Total Plans:** 25

## Overview

Establishes the complete technical foundation of the Caramello backend: async stack, Keycloak
authentication, domain-based architecture, families domain, MCP server, containerization and
test infrastructure. No additional business domain can be built safely without this
groundwork.

## Milestone Summary

**Key Decisions:**

- Keycloak as the sole auth provider (reverted Logto) — dev/prod clients already in infra
- asyncpg replaced psycopg2-binary — no SQLite support
- Domain-based architecture (users/, families/, shared/) replaced flat layers
- DSL with a `domain` field generates code in `src/caramello/{domain}/`
- FamilyInvitation redesigned: pre-registration by e-mail (D-01) vs invitation by code
- FAMILY-04/05/06 (reusable invitation flow) deferred to M2 — outside the scope of the closed family group
- Tests against caramello_dev with savepoint rollback — no separate test database
- fastapi-mcp 0.4.0 exposes FastAPI endpoints directly as MCP tools
- DB naming: caramello (prod), caramello_dev (dev)

**Tech Debt:**

- E2E UAT with real Keycloak + PostgreSQL never run in a real environment (3 items in 03-07 + 4 items in 05-HUMAN-UAT.md)
- docker build/run not verified in the sandbox (no permission on the Docker socket)
- SQLAlchemy overlaps SAWarning fixed late in M1 (after Phase 5)

**Requirements Deferred to M2:**

- FAMILY-04: reusable invitation code
- FAMILY-05: join request via invitation
- FAMILY-06: approval/rejection of requests

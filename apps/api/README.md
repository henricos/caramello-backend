# Caramello API

API Python/FastAPI do sistema Caramello — backend que centraliza dados e regras de negócio para agenda, finanças, listas de compras, saúde e entretenimento da família.

Serve um grupo fechado de 1 a 5 usuários com autenticação via Keycloak, consumido por aplicações web/mobile e agentes de IA via MCP.

Para setup, comandos e estrutura, consulte [`docs/development.md`](./docs/development.md).

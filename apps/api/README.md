# caramello-api

![version](https://img.shields.io/badge/version-2.0.0-blue)

Caramello API — hybrid REST + MCP backend in FastAPI that owns the platform's data model and business rules, authenticates via OIDC, authorizes through an e-mail allowlist plus family membership, and persists to PostgreSQL. Its entities and business endpoints are generated from a YAML DSL.

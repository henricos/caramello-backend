<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → /mcp | Cliente externo (Claude Desktop, Cursor) cruza com Bearer token não confiável |
| /mcp → endpoint REST | Token propagado via header authorization; validado por get_current_user |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | Spoofing | /mcp sem token | mitigate | `AuthConfig(dependencies=[Depends(http_bearer)])` exige Bearer; `headers=["authorization"]` propaga para get_current_user() que valida o JWT Keycloak via JWKS |
| T-05-08 | Elevation of Privilege | exposição de endpoints | mitigate | `include_operations=["list_my_families"]` é whitelist — apenas o endpoint explicitamente listado vira ferramenta MCP; demais endpoints (criar família, remover membro) NÃO são expostos |
| T-05-09 | Tampering | token expirado no cliente MCP | mitigate | get_current_user() revalida o JWT em cada chamada — sem cache de sessão server-side; token expirado é rejeitado |
</threat_model>

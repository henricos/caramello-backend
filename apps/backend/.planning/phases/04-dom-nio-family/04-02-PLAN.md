**generate_operations (scripts/generate_code.py linhas ~443-483):**

Estado atual (problemático):
```python
def generate_operations(op_data: dict[str, Any]) -> str:
    """Gera stub de operations.py a partir de dsl/operations/{domain}.yaml."""
    domain = op_data["domain"]
    operations = op_data.get("operations", [])
    # Deriva o nome da classe principal do domínio
    domain_class = domain.title()
    if domain == "user":
        domain_class = "User"
    ...
```

**Problema:** `domain.title()` produz `"Families"` para domínio `"families"`. As classes `FamiliesRead`, `FamiliesCreate`, `FamiliesUpdate` NÃO EXISTEM em `caramello.families.models` — só existem `FamilyRead`, `FamilyCreate`, `FamilyUpdate`. Sem correção, o módulo stub gerado dispara `ImportError` ao ser importado, e a workaround `sed` da Sub-task 1E do 04-03 é destruída em qualquer rerun do generator.

**Correção (permanente):** Substituir `domain.title()` por um lookup explícito num mapeamento `DOMAIN_TO_ENTITY_NAME` no topo do módulo:

```python
# Mapeia o domain (plural, do DSL) para o nome canônico da entidade canônica desse domínio.
# Necessário porque domain.title() produz nomes incorretos para domínios plurais
# (ex: "families".title() == "Families", mas a classe é "Family").
# Quando um novo domínio for adicionado (ex: "finances" → "Transaction"), incluir aqui.
DOMAIN_TO_ENTITY_NAME: dict[str, str] = {
    "user": "User",
    "users": "User",
    "family": "Family",
    "families": "Family",
}
```

E na função `generate_operations`:

```python
def generate_operations(op_data: dict[str, Any]) -> str:
    """Gera stub de operations.py a partir de dsl/operations/{domain}.yaml."""
    domain = op_data["domain"]
    operations = op_data.get("operations", [])
    # Deriva o nome da classe canônica do domínio.
    # NÃO usar domain.title(): "families".title() == "Families" (classe inexistente).
    if domain not in DOMAIN_TO_ENTITY_NAME:
        raise ValueError(
            f"domain {domain!r} não mapeado em DOMAIN_TO_ENTITY_NAME. "
            f"Adicione a entrada para o domínio antes de gerar operations.py."
        )
    domain_class = DOMAIN_TO_ENTITY_NAME[domain]
    ...
```

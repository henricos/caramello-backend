**Passo 1 — Adicionar configuração de ruff e mypy ao `pyproject.toml`:**

Adicionar as seguintes seções ao final do `pyproject.toml`:

```toml
[tool.ruff]
target-version = "py310"
line-length = 88
src = ["src"]

[tool.ruff.lint]
select = ["E", "F", "I", "UP", "B", "SIM"]
ignore = ["B008"]  # FastAPI Depends() em argumentos de função é padrão

[tool.mypy]
python_version = "3.10"
strict = false
ignore_missing_imports = true
disallow_untyped_defs = true
warn_return_any = false
warn_unused_ignores = true
```

Nota: `strict = false` com `disallow_untyped_defs = true` é a postura correta para este projeto — evita exigir anotações em código gerado e de terceiros sem ser permissivo com o código próprio.

**Passo 2 — Executar ruff e capturar erros:**

```bash
uv run ruff check src/ --output-format=text 2>&1
```

Corrigir todos os erros reportados. Os mais comuns esperados:
- `F401` (imports não usados): remover os imports
- `I001` (ordem de imports): executar `uv run ruff check src/ --fix` para auto-corrigir
- `UP` (upgrades de sintaxe Python): aceitar auto-correção

**Passo 3 — Executar mypy e corrigir erros:**

**Passo 1 — Atualizar `src/caramello/core/config.py`:**

Adicionar o campo `CORS_ORIGINS` à classe `Settings`. O campo deve aceitar uma lista de URLs separadas por vírgula quando lida do ambiente:

```python
CORS_ORIGINS: list[str] = ["http://localhost:3000", "http://localhost:5173"]
```

O pydantic-settings lida automaticamente com conversão de string separada por vírgula para `list[str]` via `env_file`. Não é necessário `field_validator` para este caso.

**Passo 2 — Atualizar `src/caramello/main.py`:**

Adicionar CORSMiddleware antes dos `include_router`. O import de `settings` já existe em outros módulos — adicioná-lo em main.py se necessário.

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from caramello.core.config import settings
from caramello.api.generated import user_router, family_router, familymember_router, familyinvitation_router

app = FastAPI(
    title="Caramello Backend",
    description="Backend API for Caramello",
    version="0.1.0",
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.CORS_ORIGINS,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Include generated routers
app.include_router(user_router.router)
app.include_router(family_router.router)
app.include_router(familymember_router.router)
app.include_router(familyinvitation_router.router)

@app.get("/")
def root() -> dict[str, str]:
    return {"message": "Welcome to Caramello API"}
```

Nota: A anotação de retorno `dict[str, str]` em `root()` é necessária para mypy com `disallow_untyped_defs = true`.

<threat_model>
## Limites de Confiança

| Limite | Descrição |
|--------|-----------|
| Browser → API | CORS controla quais origens podem fazer requisições cross-origin |
| Ambiente → aplicação | `CORS_ORIGINS` lida do ambiente — valor incorreto pode bloquear frontend ou abrir demais |

## Registro de Ameaças STRIDE

| ID | Categoria | Componente | Disposição | Plano de Mitigação |
|----|-----------|------------|------------|-------------------|
| T-03-01 | Information Disclosure | CORSMiddleware `allow_credentials=True` | mitigar | Usar lista explícita em `allow_origins` — nunca `"*"` quando credentials=True; pydantic-settings lê lista do env var |
| T-03-02 | Elevation of Privilege | CORS com origens abertas demais | mitigar | `CORS_ORIGINS` deve ser definido explicitamente em produção — `.env.example` documenta a variável; valor padrão é apenas localhost |
| T-03-03 | Tampering | `.env.example` com valor errado de DB_NAME | mitigar | Corrigido para `familia_dev` neste plano; convenção documentada em docs/apps-platform.md §5 |
</threat_model>
